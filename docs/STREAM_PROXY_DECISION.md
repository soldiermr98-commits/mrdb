# تصمیم‌گیری: استریم پروکسی یا مستقیم؟

> **خلاصه:** روی هاست اشتراکی cPanel، پروکسی PHP برای ویدیو همیشه کندتر از CDN مستقیم است. اما URL ویدیو را در DevTools پنهان می‌کند. انتخاب بین سرعت و امنیت به شما بستگی دارد.

---

## مقایسه واقع‌بینانه

| معیار | مستقیم CDN (پروکسی خاموش) | استریم پروکسی (پروکسی فعال) |
|---|---|---|
| **سرعت پخش** | سریع (CDN مستقیم، BitNinja کش می‌کند) | کند (PHP باید هر بایت را پروکسی کند) |
| **URL در DevTools** | `https://dll.mrdastbaaf.com/FA/...` (قابل دیدن) | `https://mrdastbaaf.com/wp-json/.../stream?token=...` (پنهان) |
| **اشتراک‌گذاری URL** | نیاز به Hotlink Protection (فایل `.htaccess` روی dll host) | توکن ۶۰ ثانیه‌ای، خودبه‌خود منقضی می‌شود |
| **بار سرور** | صفر (CDN همه کار را می‌کند) | بالا (PHP هر بایت را پروکسی می‌کند) |
| **هزینه پهنای باند** | یک بار (CDN → کلاینت) | دو بار (CDN → سرور → کلاینت) |
| **محدودیت کاربر هم‌زمان** | نامحدود (CDN مقیاس‌پذیر است) | محدود به منابع PHP هاست اشتراکی |
| **پشتیبانی از seek** | عالی (CDN Range request) | خوب (با بهینه‌سازی v1.7.1) |
| **حافظه سرور** | صفر | تا ۵۱۲MB per stream |

## سناریوهای توصیه‌شده

### 🅰️ مستقیم CDN + Hotlink Protection (پیشنهادی برای اکثر کاربران)

**زمان استفاده:**
- ویدیوهای آموزشی معمولی
- تعداد کاربر هم‌زمان زیاد (>۱۰ نفر)
- هاست اشتراکی با منابع محدود
- مهمترین: سرعت پخش

**راه‌اندازی:**
1. در پیشخوان وردپرس ← مستر دستباف ← تنظیمات ← «حالت استریم امن (پروکسی)» را **خاموش** کنید
2. فایل `docs/DLL_HOST_HTACCESS.sample` را به‌عنوان `.htaccess` در ریشهٔ `dll.mrdastbaaf.com` قرار دهید
3. تست کنید: URL کپی‌شده در آدرس‌بار باید ۴۰۳ بگیرد

**نتیجه:** URL در DevTools قابل دیدن است، ولی:
- اگه کسی آن را در آدرس‌بار بچسباند → ۴۰۳ Forbidden
- اگه کسی آن را در تلگرام/اینستاگرام منتشر کند → ۴۰۳ Forbidden
- در اپ مستر دستباف → پخش می‌شود (چون Referer درست دارد)

### 🅱️ استریم پروکسی (فقط برای ویدیوهای بسیار حساس)

**زمان استفاده:**
- ویدیوهای اختصاصی استاد برجسته
- ویدیوهای پولی که نباید حتی در DevTools دیده شوند
- تعداد کاربر هم‌زمان کم (<۱۰ نفر)
- هاست با منابع کافی (VPS یا هاست پرقدرت)

**راه‌اندازی:**
1. در پیشخوان وردپرس ← مستر دستباف ← تنظیمات ← «حالت استریم امن (پروکسی)» را **روشن** کنید
2. (اختیاری) Hotlink Protection روی dll host هم نگه دارید (لایه اضافی)

**نتیجه:** URL واقعی `dll.mrdastbaaf.com` هرگز در DevTools دیده نمی‌شود. ولی سرعت پخش کندتر است.

### 🅲️ ترکیبی (بهترین‌ها) — برای آینده

**ایده:** پروکسی فقط برای درس‌های خاص (تیک در صفحهٔ ویرایش درس)، بقیه مستقیم.
**وضعیت:** پیاده‌سازی نشده — اگه نیاز بود، بگویید تا اضافه کنیم.

## بهینه‌سازی‌های v1.7.1 (اگه پروکسی را انتخاب کردید)

پلاگین ۱.۷.۱ این بهینه‌سازی‌ها را دارد:

1. **غیرفعال‌کردن `zlib.output_compression`** — مهم‌ترین bottleneck روی هاست اشتراکی. PHP سعی می‌کرد خروجی را gzip کند، ولی برای stream این یعنی buffer کامل هر chunk قبل از فرستادن.
2. **غیرفعال‌کردن `output_buffering`** — به‌طور پیش‌فرض ۴۰۹۶ بایت جمع می‌کند.
3. **افزایش `memory_limit` به ۵۱۲M** — برای ویدیوهای بزرگ.
4. **استفاده از `stream_copy_to_stream`** به جای `cURL WRITEFUNCTION` با `echo` — سریع‌ترین روش PHP برای stream.
5. **ارسال Referer درست به CDN** — تا BitNinja/WAF رد نکند.
6. **غیرفعال‌کردن `Content-Encoding`** — جلوگیری از gzip دوبل.

**اگر باز هم کند بود:** پروکسی را خاموش کنید و از Hotlink Protection استفاده کنید (گزینه A).

## تست عملکرد

بعد از نصب ۱.۷.۱، این تست را انجام دهید:

```bash
# ۱) مستقیم از CDN (سرعت مرجع):
time curl -s -o /dev/null \
  -H 'User-Agent: Mozilla/5.0 (Linux; Android 13) Chrome/120.0.0.0 Mobile' \
  -H 'Referer: https://app.mrdastbaaf.com/' \
  'https://dll.mrdastbaaf.com/FA/TabloFarsh/01%20teaser%20tablo%20farsh.mp4'

# ۲) از طریق پروکسی (اگر فعال باشد — نیاز به توکن معتبر):
# ابتدا در اپ، یک ویدیو را پخش کنید و از DevTools URL پروکسی را کپی کنید
time curl -s -o /dev/null \
  -H 'User-Agent: Mozilla/5.0 (Linux; Android 13) Chrome/120.0.0.0 Mobile' \
  'https://mrdastbaaf.com/wp-json/mrdastbaaf/v1/lessons/1/stream?token=YOUR_TOKEN_HERE'
```

اگر تفاوت زمانی بیش از ۳ برابر بود، پروکسی را خاموش کنید.

## جمع‌بندی

| سوال | جواب |
|---|---|
| «URL واقعاً نمی‌شود از DevTools پنهان کرد؟» | **نه.** این حقیقت اساسی وب است. |
| «پس پروکسی چه فایده‌ای دارد؟» | URL واقعی CDN را پنهان می‌کند (به‌جای آن URL پروکسی کوتاه‌عمر می‌بینید) |
| «آیا ارزش کندی را دارد؟» | بستگی به شما دارد — برای ویدیوهای معمولی نه، برای ویدیوهای بسیار حساس بله |
| «بهترین راه چیست؟» | مستقیم CDN + Hotlink Protection (سریع + URL غیرقابل اشتراک‌گذاری) |
