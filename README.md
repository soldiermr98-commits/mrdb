# مستر دستباف (Mr. Dastbaaf) — پلتفرم PWA آموزش صنایع دستی

پلتفرم مدرن، واکنش‌گرا (موبایل‌محور)، راست‌چین (RTL) و پیش‌رونده (PWA) برای وب‌سایت آموزشی **مستر دستباف** ([mrdastbaaf.com](https://mrdastbaaf.com)).

**نسخه فعلی: `1.0.3`** (اکتبر ۲۰۲۶ — پس از سه فاز اصلاحی کامل)

### ✨ فیچرهای اضافه‌شده در v1.0.3

- **مسیریابی هش‌محور (`#/`)** — لینک مستقیم (deep link) به دوره/صفحه/دسته (`#/course/{id}`، `#/page/{slug}`، `#/catalogue?cat=...`) + پشتیبانی دکمه Back مرورگر
- **بروزرسانی خودکار PWA** — کارت اعلان «بروزرسانی جدید آماده است» (`registerType: prompt`) با دکمه بارگذاری مجدد
- **ErrorBoundary + AsyncState** — مهار کرش‌های رندر و حالت‌های یکدست loading/error/empty در همه ویوها
- **«ادامه یادگیری»** — سکشن دوره‌های در جریان با نوار پیشرفت + دکمه ادامه روی اولین درس ناتمام
- **«نشان‌شده‌ها»** — فهرست دروس بوکمارک‌شده در داشبورد با پخش مستقیم
- **فیلتر پیشرفته ادمین** — وضعیت سفارش/درگاه/جستجو روی تب «تمام سفارش‌ها»
- جستجوی کاتالوگ با debounce + گارد پاسخ‌های stale، toast سه‌واریانتی، لغو خودکار سفارش‌های رهاشده ۲۴ ساعته، دسترس‌پذیری (ARIA/focus/تاچ‌تارگت ۴۴px) و…

## 🧩 افزونه وردپرس (Mr. Dastbaaf Bridge)

- مسیر: `wordpress-plugin/mrdastbaaf-bridge/` — **نسخه `1.0.3`**
- راهنمای نصب و تنظیمات: [wordpress-plugin/README.md](wordpress-plugin/README.md)
- نکات کلیدی راه‌اندازی:
  1. افزونه را روی وردپرس نصب و فعال کنید.
  2. آپشن **`mrdastbaaf_allowed_origins`** را با دامنه واقعی PWA ذخیره کنید (CORS).
  3. یک‌بار بخش‌های صفحه اصلی (دوره‌های ویژه/پلن‌ها) را در پنل ادمین وردپرس **ذخیره کنید** تا کش محتوا ساخته شود.
  4. کرون‌جاب وردپرس را روشن نگه دارید (پاکسازی خودکار سفارش‌های رهاشدهٔ ۲۴ ساعته).

## ⚠️ محدودیت‌های نسخه پروتوتایپ (Mock Limitations)

این پروژه در فاز فعلی یک **پروتوتایپ رابط کاربری و معماری یکپارچه‌سازی** است:
- **احراز هویت پیامکی:** سیستم ورود با شماره موبایل به صورت دمو (Mock) پیاده‌سازی شده است. هیچ پیامک واقعی ارسال نمی‌شود و کد آزمایشی ورود **۱۲۳۴۵** است. همچنین کلید‌های میانبر برای ورود مستقیم با حساب هنرجو (سارا احمدی) و مدیر ارشد (علیرضا بافنده) تعبیه شده است.
- **درگاه پرداخت اینترنتی زیبال (Zibal):** درگاه به صورت شبیه‌ساز آزمایشی با دکمه‌های شبیه‌سازی پرداخت موفق، خطای بانکی و انصراف پیاده‌سازی شده است. هیچ وجه واقعی جابجا نمی‌شود. (توجه: تأیید سمت سرور با HMAC از فاز ۱ پیاده‌سازی شده و در نسخه واقعی فعال خواهد شد.)
- **پخش ویدیو:** پلیر ویدیو جهت ارزیابی تجربه کاربری، زمان‌بندی، یادداشت‌برداری، لیست دروس و نمایش **واترمارک متحرک پویا (حاوی شماره موبایل ماسک‌شده و شناسه کاربر)** شبیه‌سازی شده است.

## 🏗 یادداشت معماری: اتصال به وردپرس از طریق API اختصاصی

در نسخه نهایی، هسته مرکزی داده‌ها و هویت کاربران، **وردپرس (WordPress)** و ووکامرس خواهند بود:
1. **پایگاه داده و مرجع هویت (System of Record):** جداول `wp_users` و افزونه ورود پیامکی **اوتینو (Otino)** مرجع اصلی اعتبارسنجی کاربران باقی می‌مانند.
2. **لایه واسط امنیتی سرور (Server-Side Proxy API):** وب‌اپلیکیشن PWA هرگز مستقیماً با دسترسی‌های ممتاز دیتابیس یا کلیدهای امنیتی با وردپرس ارتباط برقرار نمی‌کند. بلکه از طریق یک لایه API امن (یک اندپوینت REST API سفارشی یا سرویس پروکسی مبتنی بر Express / Node.js) با محدودیت سطح دسترسی ارتباط می‌گیرد:
   - احراز هویت با JWT کوتاه‌مدت یا Cookie امن `HttpOnly`.
   - استعلام کاتالوگ دوره‌ها از افزونه Nias Course / ووکامرس.
   - ثبت سفارش‌های عضویت و تراکنش‌ها.
3. **اعتبارسنجی سرور به سرور زیبال:** فعال‌سازی اشتراک هرگز نباید صرفاً با ریدایرکت مرورگر کاربر انجام شود. سرور پس از دریافت پیام بازگشت درگاه، درخواست مستقیم سرور-به-سرور به `POST https://gateway.zibal.ir/v1/verify` ارسال کرده و پس از احراز صحت پاسخ شاپرک (`result == 100`)، وضعیت اشتراک کاربر را در متادیتای وردپرس آپدیت می‌کند.
4. **بررسی فیش‌های کارت به کارت:** فیش‌های واریزی در جدول سفارش‌ها با وضعیت «در انتظار بررسی» ذخیره شده و پس از تطبیق دستی توسط مدیر مالی در پنل مدیریت، اشتراک فعال می‌گردد.

## 🛡️ یادداشت امنیت استریم ویدیو (Video Security Reality)

- **فایل خام MP4 امنیت ندارد:** قرار دادن آدرس فایل‌های MP4 در کدهای کلاینت (حتی با مخفی کردن دکمه دانلود، پلیر اختصاصی یا اسکریپت‌های ضد کلیک راست) هیچ‌گونه امنیت در برابر دانلود با افزونه‌های مرورگر (مانند IDM) یا اشتراک لینک فراهم نمی‌کند.
- **راهکار نسخه نهایی:** برای محافظت در سطح تجاری، پلتفرم مستر دستباف باید به یکی از سرویس‌های تخصصی استریم امن ویدیویی متصل شود:
  - سرویس VoD امن با پروتکل HLS رمزنگاری‌شده (مانند ابرآروان یا ویدیو سی‌دی‌ان).
  - استفاده از توکن‌های امضاشده موقت (Signed URLs / Signed Cookies) با انقضای مثلاً ۱۵ دقیقه‌ای محدود به IP یا User-Agent کاربر.
  - واترمارک متحرک داینامیک سمت سرور یا کلاینت برای جلوگیری از ضبط صفحه (Screen Recording deterrence).
  - در صورت الزام حقوقی یا تجاری بالا، پیاده‌سازی DRM سخت‌افزاری (Widevine / FairPlay).

## ❓ پرسش‌های فنی و اطلاعات مورد نیاز برای پیاده‌سازی نسخه واقعی (Production Questions)

پیش از پیاده‌سازی اتصال به درگاه‌ها و سیستم‌های واقعی، اطلاعات و مستندات زیر از تیم فنی مستر دستباف مورد نیاز است:

1. **سامانه پیامک و اوتینو (Otino):**
   - آیا افزونه اوتینو اندپوینت رسمی REST API عمومی برای ارسال و تایید کد OTP در اختیار قرار می‌دهد یا نیاز به نگارش هوک اختصاصی در `functions.php` وردپرس است؟
   - پترن (Pattern) پیامک‌های تایید در پنل کاوه‌نگار / ملی‌پیامک چیست؟
2. **افزونه دوره و اعضای وردپرس (Nias Course & Membership):**
   - آیا افزونه نیاس کورس دوره‌ها را به عنوان Custom Post Type با ساختار اختصاصی ذخیره می‌کند یا روی محصولات ووکامرس سوار است؟
   - سطوح دسترسی (Entitlements) در دیتابیس چگونه ذخیره می‌شوند (در جدول `wp_usermeta` یا جدول اختصاصی)؟
3. **درگاه زیبال (Zibal):**
   - کد مرچنت (Merchant Key) درگاه فعال زیبال مستر دستباف چیست؟
   - دامنه تایید شده در زیبال جهت تنظیم URL بازگشت (Callback URL) کدام دامنه است؟
4. **میزبانی و استریم ویدیو:**
   - ویدیوهای آموزشی در حال حاضر در چه سرویسی میزبانی می‌شوند (هاست دانلود، یوتیوب، آپارات، ابرآروان، یا اسپات‌پلیر)؟
   - سیاست مورد نظر مستر دستباف برای سطح حفاظت ویدیوها چیست (استریم با امضای موقت کافی است یا حفاظت در سطح نرم‌افزار DRM نیاز است)؟
